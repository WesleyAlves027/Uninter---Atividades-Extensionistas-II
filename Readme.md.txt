# 🛍️ Plataforma E-commerce – Moda Praia (Hope Store)

Projeto de extensão universitária desenvolvido para a disciplina do curso de **Análise e Desenvolvimento de Sistemas (ADS)**, aplicado ao comércio varejista local **Moda Praia - Hope Store**, localizado no bairro de Vila do Riacho, em Aracruz – ES.

---

## 🎯 Sobre o Projeto
Este projeto tem como objetivo principal promover a transformação digital de um pequeno comércio local, criando uma presença online estruturada para a exibição de produtos, ampliação do alcance de vendas e facilitação da comunicação com os clientes da região. A iniciativa está alinhada aos **Objetivos de Desenvolvimento Sustentável (ODS)** da ONU:
* **ODS 08:** Trabalho Decente e Crescimento Econômico.
* **ODS 09:** Indústria, Inovação e Infraestrutura.

---

## 🚀 Funcionalidades
* **Catálogo de Produtos:** Exposição visual das peças de vestuário de moda praia.
* **Layout Responsivo:** Desenvolvido para adaptação fluida em dispositivos móveis (smartphones) e desktops.
* **Canal de Atendimento Direto:** Botão flutuante integrado ao WhatsApp para negociações e tirar dúvidas de forma rápida.

---

## 💻 Tecnologias Utilizadas
O projeto foi desenvolvido inteiramente com tecnologias web fundamentais (front-end estático e interativo):
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização visual, layout flexível e responsividade.
* **JavaScript:** Interatividade dinâmica na interface.
* **VS Code:** Ambiente de desenvolvimento integrado (IDE).
